# 界面与配置改进记录

## 当前布局

- **问答**：上方集中放监听与处理状态；中间逐段进度每条分两行显示，长内容可悬停查看。逐段进度与识别记录可各自折叠，折叠后释放空间给回答；识别记录和回答之间仍可拖动分隔线。点击“最大化回答”会暂时隐藏进度与识别记录，让回答占据手动提问区以下的空间；还原后保留原有折叠状态。回答标题只显示片段编号与修正标记，人设和模型保留在逐段进度与导出记录中。
- **设置 / 人设**：编辑身份、背景、范围和风格，另显示当前编辑内容匹配的人设，以及列表选中但尚未应用的人设。
- **设置 / 回答模型与密钥**：按本地、OpenAI、兼容 API 显示对应字段；云端 Key 默认保存到当前 Windows 用户凭据库，可临时显示或隐藏输入内容。
- **设置 / 语音与显示**：设备、阈值、停顿、识别方案、热词，以及字体与回答颜色。Whisper 不使用热词时禁用热词输入，但保留已填写内容。
- 保存按钮和“有未保存修改 / API Key 待保存”提示固定在设置页底部，切换子页仍可见。

## 配置行为

1. 手动提问使用当前界面字段；正在监听的语音使用启动监听时的设置快照。保存设置或应用人设不会改变正在处理的语音片段。
2. 应用人设只替换身份场景字段；当前界面的模型、设备和显示选项一同保存，不会回退到上次保存的值。编辑字段不会自动覆盖已保存的人设。
3. 保存时检查当前回答服务的地址格式：本地 llama.cpp 只允许本机 HTTP；兼容 API 使用 HTTPS，或本机 HTTP。非当前服务的字段可以暂时留空。
4. 只在用户输入 API Key 后将其保存到 Windows 凭据库；设置 JSON、对话导出和源码包均不写入真实 Key。界面区分已保存、环境变量可用、未保存及凭据库不可用。

## 验证与限制

自动化测试覆盖三页结构、未保存提示、热词启停、Key 显示切换与凭据保存、应用人设时保留其他修改、服务地址验证，以及进度和识别记录折叠、回答最大化还原与标题内容。Qt 离屏预览已检查普通、折叠和最大化后的空间分配；仍需在正常 Windows 桌面确认文字排版。真实音频与云端 API 调用不属于这轮界面验证。
